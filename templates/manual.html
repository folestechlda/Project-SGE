Três ideias bastam para usar bem o sistema.

1

O estoque calcula-se sozinho

Cada venda tira produtos do estoque. Cada compra põe produtos. Por isso o mais importante é registar tudo, na hora.

2

Cada produto tem uma unidade

Unidade, Caixa, Embalagem ou kg. Uma caixa de 6 águas pode ser vendida inteira ou às unidades: o sistema converte e mostra, por exemplo, «2 cx 3 un».

3

Cada pessoa vê o que lhe cabe

Há três perfis: Operador, Gerente e Admin. Se não vê um menu, é porque o seu perfil não o usa.

Entrar no sistema

  1. Abra o endereço do sistema no navegador.
  2. Escreva o seu utilizador {{ m(1) }} e a sua senha {{ m(2) }}.
  3. Clique em Entrar {{ m(3) }}.
Esqueceu a senha? Peça ao Administrador para a redefinir em Sistema → Utilizadores. Depois de várias tentativas erradas, o acesso fica bloqueado durante alguns minutos.

O menu à esquerda

{{ fig('menu','O menu lateral. O grupo aberto é o da página onde está.', estreita=True) }}
  • {{ m(1) }} Painel: o resumo do negócio (a página inicial).
  • {{ m(2) }} Operações: o dia a dia. Nova venda, venda a crédito, nova entrada (compra), cotações, perdas e anular venda.
  • {{ m(3) }} O item com a barra azul é a página onde está agora.
  • {{ m(4) }} Clique no nome de um grupo para o abrir ou fechar. Cada grupo reúne tarefas parecidas:
    • Estoque: estoque geral, posição, movimentações, inventário físico, auditorias.
    • Financeiro: contas a receber, clientes, fechos mensais.
    • Relatórios: relatório de gestão, balancete, vendas, extratos, perdas e validade, curva ABC.
    • Cadastros: produtos e categorias.
    • Sistema: utilizadores, configurações (só o Admin).
Em cada página há um botão ? Ajuda no topo que traz diretamente a este manual, na parte que explica essa página.

O Painel

{{ fig('painel','O Painel: indicadores, gráficos e menu.') }}
  • {{ m(1) }} Indicadores: número de produtos, valor do estoque (a custo e a preço de venda), lucro do mês e alertas.
  • {{ m(2) }} Gráficos: vendas e compras por dia, lucro e produtos mais vendidos. Mais abaixo ficam os alertas: estoque abaixo do mínimo, validade próxima e sugestões de preço.
  • {{ m(3) }} O menu.
  • {{ m(4) }} Sair (ou Encerrar): termina a sessão. Faça-o sempre que deixar o computador.
{% endcall %} {# =================== VENDER =================== #} {% call secao('vender','Fazer uma venda', TODOS, caminho='Operações → Nova venda', palavras='vender venda pesquisar produto forma de pagamento dinheiro mpesa emola cartão código confirmar') %}

É a tarefa mais usada. O sistema tira o estoque e dá um código à venda.

  1. Procure o produto {{ m(1) }}: a barra de pesquisa está sempre no topo, mesmo quando desce na página. Escreva parte do nome ou o código e carregue Enter (ou clique no produto da lista). Ele entra na lista da venda {{ m(2) }}.
  2. Repita para cada produto. Se escolher o mesmo produto outra vez, a quantidade sobe 1. Também pode escolher o produto na lista de cada linha.
  3. Cada produto ocupa uma linha {{ m(2) }}. Ajuste a quantidade com os botões − e + (ou escrevendo), confirme a unidade (unidade, caixa, kg) e o preço. O ✕ tira a linha.
  4. No talão, à direita, veja o total {{ m(4) }} e escolha a forma de pagamento {{ m(3) }}: Dinheiro, M-Pesa, e-Mola, Cartão ou Transferência. É obrigatório: é por aqui que depois se confere o dinheiro recebido.
  5. Clique em Registar venda {{ m(5) }} e confirme em Registar.
  6. O sistema mostra o código da venda. Guarde-o: é com ele que se anula a venda, se foi por engano.
{{ fig('venda_pesquisa','Passo 1: a pesquisa mostra os produtos parecidos; carregue Enter ou clique para adicionar.') }} {{ fig('venda_form','Venda com três produtos: lista à esquerda, talão com total e pagamento à direita.') }}
{{ fig('venda_confirmar','O sistema pede confirmação antes de tirar o estoque.', estreita=True) }} {{ fig('venda_ok','Venda registada: guarde o código.') }}
Cliente e Observações são opcionais, no talão. A data vem preenchida com hoje.
Avisos. Se vender abaixo do custo, o sistema avisa e pede para confirmar. Se pedir mais do que há em estoque, não deixa registar: confira a quantidade ou registe primeiro a compra.
{% endcall %} {# =================== CRÉDITO =================== #} {% call secao('credito','Venda a crédito (fatura)', TODOS, caminho='Operações → Venda a crédito', palavras='fatura crédito cliente dívida vencimento nuit iva') %}

Use quando o cliente leva a mercadoria e paga depois. O sistema cria uma fatura e a dívida fica em Contas a receber.

  1. Em Cliente, escreva o Nome do cliente {{ m(1) }} (obrigatório). NUIT, contacto e morada são opcionais, mas aparecem na fatura.
  2. Na faixa azul-clara, defina o Vencimento {{ m(2) }}: até quando o cliente deve pagar. Pode indicar a condição de pagamento (ex.: 30 dias) e o IVA (ou marcar Isenta de IVA).
  3. Pesquise e adicione os produtos {{ m(3) }}, como numa venda normal; cada produto fica numa linha {{ m(4) }}.
  4. Confira o total da fatura na faixa azul em baixo e clique em Registar venda a crédito {{ m(5) }}. O sistema tira o estoque e cria a fatura (por exemplo FT 2026/00001).
{{ fig('credito','Venda a crédito: cliente, vencimento, produtos e total da fatura sempre à vista em baixo.') }}
A fatura pode ser aberta e impressa em PDF em Financeiro → Contas a receber.
Venda a crédito não é dinheiro recebido. O dinheiro só conta quando o cliente pagar (próxima secção).
{% endcall %} {# =================== RECEBER =================== #} {% call secao('receber','Receber o pagamento de uma dívida', GER, caminho='Financeiro → Contas a receber', palavras='dívida pagamento recibo liquidar fatura cliente parcial') %}
  1. Em Contas a receber, abra a fatura do cliente.
  2. Em Liquidar / Pagamento, escreva o Valor a pagar {{ m(1) }}. Pode ser só uma parte.
  3. Escolha a Forma de pagamento {{ m(2) }}: é onde o dinheiro entrou (caixa, banco, M-Pesa…).
  4. Clique em Emitir Recibo {{ m(3) }}. O recibo fica em PDF e o saldo da fatura diminui. Quando chega a zero, a fatura fica Liquidada.
{{ fig('conta_receber','Fatura a crédito: produtos, saldo e formulário de pagamento.') }}
O que cobrar entra no relatório de gestão como «Dívidas cobradas», no canal que escolheu.
{% endcall %} {# =================== COTAÇÕES =================== #} {% call secao('cotacoes','Fazer uma cotação (proposta ao cliente)', TODOS, caminho='Operações → Cotações → Nova cotação', palavras='cotação proposta orçamento cliente validade desconto aprovar converter') %}

Use quando o cliente pede um preço antes de comprar. A cotação não tira estoque e tem uma data de validade.

  1. Escreva o Cliente {{ m(1) }} (obrigatório). Email e telefone são opcionais.
  2. Confirme até quando a cotação vale em Válida até {{ m(2) }}.
  3. Na tabela {{ m(3) }}, escolha o produto: o preço vem preenchido, e pode pôr quantidade e desconto (%). Use + Adicionar item para mais produtos.
  4. Veja o total {{ m(4) }} e clique em Guardar cotação {{ m(5) }}.
{{ fig('cotacao','Nova cotação: cliente, validade, itens com desconto e total.') }}
Depois de guardada, a cotação pode ser exportada, aprovada ou rejeitada e, se o cliente aceitar, convertida em venda ou fatura.
{% endcall %} {# =================== COMPRAR =================== #} {% call secao('comprar','Registar uma compra (entrada de mercadoria)', TODOS, caminho='Operações → Nova entrada (compra)', palavras='compra entrada fornecedor custo nota fiscal mercadoria') %}

Sempre que chegar mercadoria, registe a entrada. Sem isso, o estoque fica menor do que a realidade e o sistema vai recusar vendas.

  1. Em Produto comprado, escreva o nome ou código {{ m(1) }} e escolha na lista. Aparecem o saldo atual, a unidade e o último custo.
  2. Em Quantidade e custo, indique a Quantidade {{ m(2) }} e a Unidade da compra {{ m(3) }}: se comprou 10 caixas, escolha Caixa.
  3. Escreva o Preço de custo {{ m(4) }} por essa unidade (o preço de uma caixa, se escolheu Caixa). A caixa azul mostra o custo do produto antes → depois desta compra.
  4. Em Documento e fornecedor, preencha o Fornecedor {{ m(5) }} e, se quiser, a nota fiscal e a data.
  5. Confira o valor da compra (quantidade × preço) no rodapé e clique em Registar entrada {{ m(6) }}. Confirme.
{{ fig('entrada','Entrada de 10 kg de um produto, em três blocos, com o valor da compra no rodapé.') }}
O sistema recalcula o custo do produto com cada compra. Por isso os preços de custo têm de ser os da fatura do fornecedor.
{% endcall %} {# =================== ANULAR =================== #} {% call secao('anular','Anular uma venda registada por engano', TODOS, caminho='Operações → Anular venda', palavras='anular venda engano erro código repor estoque cancelar apagar') %}

Enganou-se numa venda? Não a apague: anule-a pelo código. O estoque volta e fica registado quem anulou e porquê.

  1. Abra Operações → Anular venda.
  2. Na primeira imagem, escreva o código da venda {{ m(1) }} (ex.: V-000035) e clique em Procurar venda {{ m(2) }}. Ou clique em Abrir {{ m(3) }} numa venda de Vendas recentes.
  3. Confirme que é a venda certa: veja os produtos e o valor.
  4. Na segunda imagem, escreva o motivo da anulação {{ m(1) }} (obrigatório).
  5. Clique em Anular venda e repor estoque {{ m(2) }} (segunda imagem).
{{ fig('anular_1','Passo 2: procurar pelo código ou escolher nas vendas recentes.') }} {{ fig('anular_2','Passos 3 a 5: confirmar a venda, escrever o motivo e anular.') }}
Onde está o código? Na mensagem verde logo a seguir a registar a venda, na coluna Código das Movimentações e na lista de Vendas recentes.
  • O Operador só anula vendas suas e do próprio dia. Gerente e Admin anulam qualquer venda.
  • Vendas a crédito anulam-se pela fatura, em Contas a receber → Anular fatura (repõe estoque), e só se ainda não tiverem pagamentos.
  • Errou só na quantidade? Anule a venda e registe-a de novo, certa.
As anulações ficam sempre registadas (lista «Anulações registadas») e aparecem no relatório de gestão. Anular não esconde nada: serve para corrigir, com rasto.
{% endcall %} {# =================== PERDAS =================== #} {% call secao('perdas','Registar uma perda', TODOS, caminho='Operações → Perdas', palavras='perda quebra validade furto consumo interno desperdício') %}

Produto que se partiu, estragou, passou do prazo ou foi levado: tem de sair do estoque, senão o sistema acha que ainda o tem.

  1. Escolha o Produto {{ m(1) }}.
  2. Escreva a Quantidade {{ m(2) }}.
  3. Escolha o Motivo {{ m(3) }}: Vencimento, Quebra, Furto, Consumo Interno ou Outro. Seja sincero: o motivo aparece nos relatórios.
  4. Se quiser, indique a data e uma observação (ex.: «caixa caiu no armazém»).
  5. Clique em Registar Perda {{ m(4) }}.
{{ fig('perdas','Formulário de perdas e histórico.') }}
Uma perda não tem código e não se anula como uma venda. Se registou uma perda errada, fale com o Gerente.
{% endcall %} {# =================== ESTOQUE =================== #} {% call secao('estoque','Consultar o estoque e os movimentos', TODOS, caminho='Estoque → Posição de estoque / Estoque geral / Movimentações', palavras='posição saldo quanto tenho movimentos histórico exportar pdf excel estoque geral mínimo') %}

Quanto tenho agora? — Posição de estoque

{{ fig('posicao','Posição de estoque: saldo, valor e situação de cada produto.') }}

Mostra o saldo de cada produto, o valor a custo e a situação (por exemplo, abaixo do mínimo). Pode filtrar por categoria e imprimir ou exportar para PDF e Excel.

O que aconteceu? — Movimentações

{{ fig('movimentos','Histórico de entradas e saídas. A coluna «Código» identifica cada venda.') }}

Lista todas as entradas e saídas, com data, produto, quantidade e valor. A coluna Código {{ m(1) }} é o código da venda, para a anular se preciso. Use os filtros de data e o botão Exportar (PDF ou Excel).

Resumo de um período — Estoque geral

Em Estoque → Estoque geral escolhe um período e vê, por categoria: valor inicial + compras − custo das vendas − perdas = valor final. É a «conta» do estoque.

Em Relatórios há ainda: vendas, extratos por produto ou cliente, perdas e validade, e curva ABC (os produtos que mais pesam).
{% endcall %} {# =================== CONTAGEM =================== #} {% call secao('contagem','Contar o estoque (inventário físico e auditorias)', TODOS, caminho='Estoque → Inventário físico / Auditorias', palavras='inventário contagem auditoria diferença divergência ajuste prateleira') %}

De tempos a tempos, conte o que há na prateleira e compare com o sistema. Diferenças podem ser erros de registo, perdas ou desfalques.

Inventário físico (contar e comparar)

  1. Conte os produtos na prateleira e escreva o número em Contagem física {{ m(1) }}, produto a produto.
  2. O saldo do sistema fica escondido (******) de propósito, para a contagem ser honesta. Ao escrever a contagem de um produto e sair do campo, aparecem o saldo {{ m(2) }} e a diferença {{ m(3) }}: verde = certo, vermelho = falta, amarelo = sobra.
  3. No fim da lista, clique em Guardar contagem. Pode também pedir o PDF da contagem.
{{ fig('inventario','Inventário físico: nas duas primeiras linhas a contagem já foi escrita (aparecem saldo e diferença); as outras continuam escondidas.') }}
Guardar a contagem não muda o estoque: serve de registo e de comparação. Produtos que não são em kg devem ser contados em números inteiros.

Auditoria (para corrigir o estoque oficialmente) Gerente / Admin

  1. Estoque → Auditorias → Nova: indique as datas, o tipo e a tolerância aceitável.
  2. Congele o estoque teórico (a «fotografia» do sistema) e registe a contagem de cada produto.
  3. Para cada divergência, justifique, peça nova contagem ou aceite.
  4. Feche a auditoria: as diferenças acima da tolerância geram ajustes no estoque, ficando tudo registado.
{% endcall %} {# =================== CAIXA =================== #} {% call secao('caixa','Conferir o dinheiro e ler o Relatório de gestão', GER, caminho='Relatórios → Relatório de gestão', palavras='relatório gestão caixa banco mpesa emola conferir diferença desfalque semestre mês falta sobra auditoria') %}

É o relatório do gestor: mostra o que foi vendido e comprado, quanto dinheiro devia ter entrado em cada conta, compara com o que realmente entrou e escreve as diferenças. Serve para um mês ou um semestre.

Passo 1 — Escolher o período e ler a conclusão

  1. Escolha as datas ou um atalho {{ m(1) }}: Este mês, Mês anterior, Semestre atual ou Semestre anterior. Clique em Gerar.
  2. Leia a faixa de conclusão {{ m(2) }}. Verde: sem problemas. Amarelo: há pontos a acompanhar. Vermelho: há diferenças ou desfalques.
  3. A lista numerada {{ m(3) }} diz exatamente o que verificar (caixa por conferir, anulações, perdas…).
{{ fig('gestao_1','Início do relatório: período, conclusão e pontos de atenção.') }}

Passo 2 — Conferir o dinheiro

A secção 3. Recebimentos mostra, para cada canal (Caixa, Banco, M-Pesa, e-Mola), o que o sistema espera que tenha entrado: vendas à vista mais dívidas cobradas.

  1. Veja o valor Esperado {{ m(1) }} de cada canal.
  2. Conte o dinheiro real e escreva em Conferido {{ m(2) }}: no Caixa, o dinheiro contado; no Banco, o valor no extrato; em M-Pesa e e-Mola, o valor no extrato da carteira.
  3. Clique em Guardar conferência {{ m(4) }}.
  4. O sistema calcula a Diferença e escreve o Resultado {{ m(3) }}. Se souber a causa (ex.: troco), escreva a justificação ao lado.
{{ fig('gestao_2','Conferência: o sistema esperava 48 800,00 no Caixa; foram contados menos 300,00 e o relatório escreve «FALTAM 300,00 MT».') }}

FALTAM

O sistema regista mais do que foi contado. Possível desfalque ou venda não cobrada.

SOBRAM

Foi contado mais do que o sistema regista. Possível venda não registada ou erro de lançamento.

Sem diferença

O dinheiro bate certo com as vendas.

O que o relatório tem

  • 1. Vendas: total, custo, lucro e margem; à vista, a crédito e anuladas; vendas abaixo do custo.
  • 2. Compras: total e por fornecedor.
  • 3. Recebimentos: esperado vs conferido, por canal (acima).
  • 4. Estoque: valor inicial, compras, custo das vendas, perdas e valor final.
  • 5. Contagens físicas e diferenças: o que as contagens e auditorias encontraram a menos ou a mais.
  • 6. Vendas anuladas: cada anulação, com motivo e quem a fez.
  • Evolução mês a mês, útil em períodos longos como um semestre.
Use os botões Imprimir, PDF e Excel no topo para guardar ou entregar o relatório.
«Sem forma indicada» significa venda sem forma de pagamento: o dinheiro dessa venda não se consegue conferir. Escolha sempre a forma de pagamento ao vender.
Uma diferença é um sinal para investigar, não uma acusação. Comece pelas anulações, pelas vendas sem forma de pagamento e pelas perdas.
{% endcall %} {# =================== PRODUTOS =================== #} {% call secao('produtos','Cadastrar um produto novo', GER, caminho='Cadastros → Produtos → Novo produto', palavras='produto cadastro novo categoria preço custo venda unidade mínimo validade código segurança') %}
  1. Escreva o Nome do produto {{ m(1) }}. O código é gerado sozinho.
  2. Escolha a Categoria {{ m(2) }}.
  3. Escolha a Unidade de medida {{ m(3) }}: Unidade, Caixa, Embalagem ou kg.
  4. Se escolheu Caixa ou Embalagem, indique quantas unidades vêm em cada uma {{ m(4) }} (ex.: 12). Para Unidade e kg, deixe 1.
  5. Escreva o preço de custo {{ m(5) }} e o preço de venda de uma unidade avulsa (uma garrafa, um pacote, um kg). O sistema multiplica sozinho quando vender caixas.
  6. Defina o estoque mínimo {{ m(6) }}: abaixo deste número o sistema avisa que é preciso comprar.
  7. Clique em Guardar Produto {{ m(7) }}.
{{ fig('produto_novo','Formulário de novo produto.') }}
Pode ainda indicar validade, fornecedor e observações. Categorias criam-se em Cadastros → Categorias.
Para editar um produto o sistema pode pedir um código de segurança, definido pelo Administrador, para que alterações de preço fiquem controladas.
{% endcall %} {# =================== ADMIN =================== #} {% call secao('admin','Utilizadores e cópia de segurança (backup)', ADM, caminho='Sistema → Utilizadores / Configurações', palavras='utilizador usuário perfil senha redefinir backup restaurar cópia segurança configurações empresa') %}

Criar e gerir utilizadores

  1. Em Sistema → Utilizadores, preencha o Nome completo {{ m(1) }} e o Login {{ m(2) }}.
  2. Escolha o Perfil {{ m(3) }}: Operador (dia a dia), Gerente (relatórios e financeiro) ou Admin (tudo).
  3. Defina uma senha forte (mínimo 8 caracteres, com letra, número e símbolo) e clique em Guardar {{ m(4) }}.
{{ fig('usuarios','Criar um utilizador e escolher o perfil.') }}
Senha esquecida? Abra o utilizador na lista, escreva uma senha nova e guarde. Um utilizador pode ser desativado sem perder o histórico.

Fazer backup (cópia de segurança)

  1. Abra Sistema → Configurações e desça até Backup e Restauração.
  2. Clique em Baixar backup atual {{ m(1) }}. É descarregado um ficheiro .db com todos os dados.
  3. Guarde o ficheiro num sítio seguro (pen, email, outro computador).
  4. Para repor uma cópia, escolha o ficheiro e clique em Restaurar backup {{ m(2) }}.
{{ fig('backup','Cartão «Backup e Restauração» das Configurações.') }}
Faça backup toda a semana. Restaurar uma cópia substitui os dados atuais. O sistema guarda um backup automático antes, mas só restaure se tiver a certeza.

Problemas comuns

Registei uma venda errada. O que faço?

Anule-a pelo código em Operações → Anular venda e registe-a de novo, certa. Veja a secção Anular uma venda.

Não encontro o código de uma venda.

Abra Operações → Anular venda: as vendas mais recentes estão listadas com o código. Também está na coluna Código das Movimentações.

O sistema diz «Estoque insuficiente».

Está a vender mais do que o sistema acha que há. Confira a quantidade e a unidade (caixa ou unidade avulsa). Se a mercadoria chegou e não foi registada, faça primeiro a entrada (compra).

Um produto não aparece na pesquisa.

Glossário

Estoque / saldo
Quantidade que o sistema acha que há de cada produto.
Entrada
Mercadoria que chega (compra). Aumenta o estoque.
Saída
Mercadoria que sai (venda, perda). Diminui o estoque.
Movimentação
Qualquer entrada ou saída registada.
Código da venda
Identificador de uma venda (ex.: V-000035). Serve para a localizar e anular.
Fatura (FT)
Documento de uma venda a crédito. Fica em Contas a receber até ser paga.
Liquidar
Registar o pagamento de uma dívida e emitir o recibo.
Custo / Preço de venda
Quanto custou ao negócio / por quanto se vende. A diferença é o lucro.
Margem
Parte do preço de venda que é lucro (em %).
Estoque mínimo
Número abaixo do qual o sistema avisa que é preciso comprar.
Inventário físico
Contar a mercadoria na prateleira e comparar com o sistema.
Auditoria
Contagem formal que, ao fechar, ajusta o estoque às diferenças encontradas.
Divergência
Diferença entre o que o sistema diz e o que se contou.
Conferência
Comparar o dinheiro que devia ter entrado com o que realmente entrou.
Canal
Onde o dinheiro entra: Caixa, Banco, M-Pesa ou e-Mola.
Desfalque
Falta de dinheiro ou mercadoria sem explicação.
Backup
Cópia de segurança de todos os dados.
